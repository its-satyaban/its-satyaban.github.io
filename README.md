## GitHub Pages

Recommended repository: `satyabanchoudhury.github.io` and branch: `main`.

In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.

After publishing, keep **HTTPS** enforced.

## Security checklist

1. Enable 2FA/passkey on the GitHub account.
2. Keep secret scanning and push protection enabled for the public repository.
3. Never publish production firewall/VPN/server configuration or company screenshots containing sensitive data.
4. Rotate/revoke any real credential that is accidentally exposed.
