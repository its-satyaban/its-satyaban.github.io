# Security Notes

This repository contains the public source for a static professional portfolio.

## Do not commit

- passwords, API keys, access tokens, private keys or certificates
- production firewall, VPN, switch or server configuration backups
- internal IP addressing, credentials, secrets or confidential screenshots
- confidential company documents or audit evidence

## Reporting

For website security issues, use the contact information in `.well-known/security.txt`.

## Repository controls

Keep GitHub account MFA/passkeys enabled and use GitHub secret scanning/push protection where available. Never bypass a secret-detection warning for a real credential.
